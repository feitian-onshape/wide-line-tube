📊 Lighting Composition

color = 0.1 × base
      + base × (diff₁×0.85 + diff₂×0.35)
      + white × (spec₁×0.6 + spec₂×0.2)
      + (0.35,0.55,1.0) × rim × 0.4

color = color / (color + 0.85) ← Reinhard
color = pow(color, 1/2.2)    ← Gamma

🔑 Key Insight — Virtual Normal

  • The strip is flat in screen space — only 2 vertices per curve point
  • The side attribute (−1 left, +1 right) is interpolated across each fragment
  • angle = side × π/2 maps the strip width to the visible half-cylinder [−90°, +90°]
  • The reconstructed normal N = cos(θ)·right + sin(θ)·up gives each fragment a unique direction in the plane perpendicular to the curve tangent
  • Standard Blinn-Phong on this virtual normal produces convincing cylindrical shading

⚡ Z-Fighting Prevention

  • Problem: Wireframe lines share exact depth with solid strip faces
  • Solution: gl.polygonOffset(1.0, 1.0) on solid pass pushes triangles behind the wireframe lines
  • Disabled when wireframe is off for maximum depth precision
